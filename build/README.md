# 🏗️ **BUILD - ЗБІРКА ПРОЕКТУ**

## 📁 **Структура папки build/**

Ця папка містить всі файли, пов'язані зі збіркою, розгортанням та виконанням проекту. Включає скомпільований код, скрипти розгортання та конфігураційні файли.

---

## 🎯 **ОСНОВНІ КОМПОНЕНТИ**

### **📦 dist/** - Скомпільований код
TypeScript код, скомпільований в JavaScript:
- **index.js** - головний файл додатку
- **commands/** - скомпільовані команди
- **services/** - скомпільовані сервіси
- **core/** - скомпільоване ядро системи
- **utils/** - скомпільовані утиліти

### **📜 scripts/** - Скрипти розгортання
Скрипти для автоматизації процесів:
- **deploy-production.js** - розгортання в продакшн
- **deploy.sh** - bash скрипт розгортання
- **start.js** - скрипт запуску

### **⚙️ config/** - Конфігурація збірки
Конфігураційні файли для різних середовищ:
- **production/** - конфігурація продакшн
- **development/** - конфігурація розробки
- **testing/** - конфігурація тестування

---

## 🔧 **ДЕТАЛЬНИЙ ОПИС**

### **📦 Dist Directory**

#### **Структура скомпільованого коду**
```
dist/
├── index.js              # Головний файл
├── commands/             # Команди бота
│   ├── BaseCommand.js
│   ├── SearchCommand.js
│   ├── AIAssistantCommand.js
│   └── ...
├── services/             # Сервіси
│   ├── AIService.js
│   ├── GoogleService.js
│   ├── CacheService.js
│   └── ...
├── core/                 # Ядро системи
│   ├── Bot.js
│   ├── CommandManager.js
│   └── ...
├── utils/                # Утиліти
│   ├── logger.js
│   ├── formatters.js
│   └── ...
└── types/                # Типи (для TypeScript)
```

#### **Особливості збірки**
- **Оптимізація** - мініфікація коду
- **Tree Shaking** - видалення невикористаного коду
- **Source Maps** - карти джерел для дебагу
- **Type Checking** - перевірка типів

### **📜 Scripts Directory**

#### **deploy-production.js**
Скрипт для розгортання в продакшн:
- **Валідація** - перевірка конфігурації
- **Збірка** - компіляція TypeScript
- **Тестування** - запуск тестів
- **Розгортання** - завантаження команд Discord
- **Моніторинг** - перевірка стану після розгортання

#### **deploy.sh**
Bash скрипт для автоматизації:
- **Підготовка** - перевірка залежностей
- **Збірка** - компіляція проекту
- **Тестування** - запуск тестів
- **Розгортання** - розгортання в різні середовища
- **Валідація** - перевірка успішності розгортання

#### **start.js**
Скрипт запуску додатку:
- **Перевірка середовища** - валідація змінних середовища
- **Ініціалізація** - ініціалізація сервісів
- **Запуск** - запуск бота
- **Моніторинг** - моніторинг стану

### **⚙️ Config Directory**

#### **Production Configuration**
Налаштування для продакшн середовища:
- **Оптимізація** - максимальна продуктивність
- **Безпека** - посилена безпека
- **Моніторинг** - детальний моніторинг
- **Логування** - структуроване логування

#### **Development Configuration**
Налаштування для розробки:
- **Debug режим** - детальне логування
- **Hot Reload** - автоматичне перезавантаження
- **Source Maps** - карти джерел
- **Dev Tools** - інструменти розробки

#### **Testing Configuration**
Налаштування для тестування:
- **Mock дані** - тестові дані
- **Isolation** - ізоляція тестів
- **Coverage** - покриття тестами
- **Performance** - тести продуктивності

## 🚀 **ВИКОРИСТАННЯ**

### **📦 Збірка проекту**
```bash
# Розробка
npm run build

# Продакшн
npm run build:prod

# Спостереження за змінами
npm run build:watch
```

### **🚀 Розгортання**
```bash
# Локальне розгортання
npm run deploy:local

# Тестове розгортання
npm run deploy:test

# Продакшн розгортання
npm run deploy:prod

# Docker розгортання
npm run deploy:docker
```

### **▶️ Запуск**
```bash
# Розробка
npm run start:dev

# Тестування
npm run start:test

# Продакшн
npm run start:prod

# Docker
npm run start:docker
```
