# Кодекс поведінки учасників

Ми дотримуємося принципів поваги, відкритості та безпеки для всіх учасників.

- Поважайте інших. Нульова толерантність до дискримінації, переслідувань, мови ненависті.
- Дискусії тримайте ввічливими, по суті, без особистих нападок.
- Конструктивний фідбек вітається. Критика має бути доброзичливою і обґрунтованою.
- Дотримуйтеся ліцензії та правил безпеки проєкту.
