# 📋 Довідник команд
# Повна довідка команд Discord AI Assistant Bot

## 🎯 Вступ

Цей довідник містить повний перелік усіх команд, доступних у Discord AI Assistant Bot, з детальним описом параметрів та прикладів використання.

## 🔍 Команди пошуку

### /пошук

Базова команда для пошуку інформації в документах.

**Синтаксис:**
```
/пошук запит:"<текст>" [тип_документа:"<тип>"] [дата_від:"<дата>"] [дата_до:"<дата>"] [підрозділ:"<назва>"] [пріоритет:"<рівень>"] [ліміт:<число>]
```

**Параметри:**
- `запит` (обов'язковий) - текст для пошуку
- `тип_документа` (опційно) - фільтр за типом документа
- `дата_від` (опційно) - пошук з певної дати (формат: ДД.ММ.РРРР)
- `дата_до` (опційно) - пошук до певної дати (формат: ДД.ММ.РРРР)
- `підрозділ` (опційно) - фільтр за підрозділом
- `пріоритет` (опційно) - фільтр за пріоритетом
- `ліміт` (опційно) - кількість результатів (за замовчуванням: 10)

**Приклади:**
```
/пошук запит:"особовий склад" тип_документа:"накази"
/пошук запит:"запит на постачання" дата_від:"01.01.2025" ліміт:5
```

### /розумний-пошук

Розширена команда пошуку з додатковими фільтрами.

**Синтаксис:**
```
/розумний-пошук [кількість_вище:<число>] [кількість_нижче:<число>] [ціна_вище:<число>] [ціна_нижче:<число>]
```

**Параметри:**
- `кількість_вище` (опційно) - мінімальна кількість
- `кількість_нижче` (опційно) - максимальна кількість
- `ціна_вище` (опційно) - мінімальна ціна
- `ціна_нижче` (опційно) - максимальна ціна

**Приклади:**
```
/розумний-пошук кількість_вище:100 ціна_нижче:1000
```

## 🤖 AI команди

### /ai

Команда для взаємодії з AI асистентом.

**Синтаксис:**
```
/ai запит:"<текст>" [контекст:"<текст>"]
```

**Параметри:**
- `запит` (обов'язковий) - ваш запит до AI
- `контекст` (опційно) - додатковий контекст для AI

**Приклади:**
```
/ai запит:"проаналізуй особовий склад"
/ai запит:"створи звіт по залишках на складі" контекст:"станом на 01.04.2025"
```

### /analyze-doc

Аналіз документів з різних аспектів.

**Синтаксис:**
```
/analyze-doc file:"<назва файлу>" type:"<тип аналізу>"
```

**Параметри:**
- `file` (обов'язковий) - назва або ID файлу
- `type` (обов'язковий) - тип аналізу:
  - `full` - повний аналіз
  - `structure` - структурний аналіз
  - `summary` - підсумування
  - `actions` - витяг дій
  - `compliance` - перевірка відповідності
  - `quality` - оцінка якості

**Приклади:**
```
/analyze-doc file:"Наказ №123" type:"full"
/analyze-doc file:"Звіт про постачання" type:"summary"
```

## 📄 Команди роботи з документами

### /документи

Управління документами.

**Синтаксис:**
```
/документи <підкоманда>
```

**Підкоманди:**
- `додати` - додати новий документ
- `список` - показати список документів
- `оновити` - оновити існуючий документ
- `видалити` - видалити документ

**Приклади:**
```
/документи особовий-склад список
/документи техніка додати назва:"Танк Т-72"
```

### /файли

Робота з файлами Google Drive.

**Синтаксис:**
```
/файли <підкоманда>
```

**Підкоманди:**
- `пошук` - пошук файлів
- `читати` - читання вмісту файлу
- `аналіз` - AI-аналіз файлу
- `звіт` - створення звіту за файлом

**Приклади:**
```
/файли пошук запит:"назва файлу"
/файли читати id:"1abc123def456ghi"
```

Генерує аналітичні звіти.

## 🔒 Обмеження та безпека

### Rate limiting

- Пошук: 10 запитів за хвилину
- AI аналіз: 5 запитів за 2 хвилини
- Експорт: 3 запити за 5 хвилин
- Загальні команди: 20 запитів за хвилину

### Валідація даних

- Максимальна довжина тексту: 500 символів
- Максимальна довжина пошукового запиту: 200 символів
- Максимальна довжина AI запиту: 1000 символів
