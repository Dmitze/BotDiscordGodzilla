# ❓ Часті питання
# Довідник з часто задаваних питань Discord AI Assistant Bot

## 📋 Загальні питання

### Що таке Discord AI Assistant Bot?

Discord AI Assistant Bot (Godzilla) - це потужний бот, розроблений для автоматизації роботи з документами, аналізу даних та підтримки операційної діяльності. Спеціально адаптований для потреб Збройних Сил України та критично важливих організацій.

### Які основні можливості бота?

Основні можливості:
- AI асистент для аналізу даних
- Розумний пошук по документах
- Управління документами Google Sheets/Drive
- Аналітика та статистика
- Операційна підтримка
- Комплексна система безпеки

### Чи безпечне використання бота?

Так, бот реалізує багаторівневу систему безпеки:
- Контроль доступу через ролі Discord
- Шифрування даних
- PII-маскування у логах
- Rate limiting для запобігання зловживанням
- Валідація всіх вхідних даних

## 🔧 Встановлення та налаштування

### Які системні вимоги для запуску бота?

Мінімальні вимоги:
- Node.js 18 або новіша версія
- Git для клонування репозиторію
- Google Cloud обліковий запис
- Discord Developer обліковий запис

Опційно:
- Docker для контейнеризації
- Redis для кешування
- PostgreSQL для зберігання даних

### Як налаштувати Discord бота?

1. Перейдіть на Discord Developer Portal
2. Створіть новий додаток
3. Додайте бота до додатку
4. Скопіюйте токен
5. Увімкніть необхідні "Privileged Gateway Intents"

### Як налаштувати інтеграцію з Google?

1. Перейдіть на Google Cloud Console
2. Створіть новий проект або виберіть існуючий
3. Увімкніть Google Sheets API та Google Drive API
4. Створіть Service Account
5. Завантажте ключ Service Account
6. Надайте доступ до ваших таблиць/документів

### Як налаштувати локальний AI (Ollama)?

1. Встановіть Ollama з офіційного сайту
2. Завантажте модель:
   ```bash
   ollama run llama3.1
   ```
3. Вкажіть налаштування в .env файлі:
   ```env
   AI_PROVIDER=ollama
   OLLAMA_BASE_URL=http://localhost:11434
   ```

## 🤖 Використання AI

### Які AI моделі підтримуються?

Підтримуються:
- OpenAI (GPT-3.5, GPT-4)
- Локальні моделі через Ollama (Llama, Mistral, та інші)

### Чи безпечне використання AI?

Так, при використанні локальних моделей (Ollama):
- Дані не передаються третім сторонам
- Всі обробки відбуваються локально
- Відсутні обмеження API ключів

### Як змінити AI модель?

Адміністратор може змінити модель у файлі .env:
```env
AI_PROVIDER=ollama
OLLAMA_MODEL=llama3.1
```

Або користувачі можуть використовувати команду:
```
/налаштування ai-провайдер провайдер:"ollama" модель:"llama3.1"
```

## 🔍 Пошук та документи

### Як працює пошук?

Пошук використовує гібридний підхід:
- Full-text search (FTS) для швидкого пошуку
- Векторні ембеддінги для семантичного пошуку (опційно)
- Фільтрація за метаданими

### Які типи документів підтримуються?

Підтримуються:
- Google Sheets
- Google Docs
- PDF файли
- Microsoft Word документи
- Текстові файли
- Зображення (з OCR)

### Як додати новий документ?

Використовуйте команду:
```
/документи додати назва:"Назва документу" тип:"Тип документу"
```

Або завантажте файл через:
```
/файли завантажити файл:<прикріплений файл>
```

## 🔐 Безпека та доступ

### Як отримати доступ до бота?

Зверніться до адміністратора вашого Discord сервера для отримання необхідних ролей:
- Бот-Користувач
- Sheets-Доступ
- AI-Доступ
- Експорт-Доступ

### Які ролі існують?

- **Адміністратор** - повний доступ до всіх функцій
- **Бот-Користувач** - базові команди
- **Sheets-Доступ** - робота з Google Sheets
- **AI-Доступ** - AI функції
- **Експорт-Доступ** - експорт даних

### Як працює система обмежень?

Бот реалізує систему rate limiting:
- Пошук: 10 запитів за хвилину
- AI аналіз: 5 запитів за 2 хвилини
- Експорт: 3 запити за 5 хвилин
- Загальні команди: 20 запитів за хвилину

## 📊 Аналітика та звіти

### Які типи аналітики доступні?

Доступні типи аналітики:
- Загальна аналітика використання
- Аналітика пошуку
- Аналітика команд
- Аналітика активності користувачів

### Як експортувати дані?

Більшість команд мають кнопку "Експорт" у відповіді:
1. Виконайте команду
2. Натисніть кнопку "Експорт"
3. Оберіть формат (Excel, CSV, PDF, DOCX)
4. Завантажте файл

### Які формати експорту підтримуються?

Підтримуються формати:
- Microsoft Excel (.xlsx)
- CSV (.csv)
- PDF (.pdf)
- Microsoft Word (.docx)

Система операцій дозволяє:

## 🛠️ Усунення проблем

### Бот не відповідає

Перевірте:
1. Правильність Discord токена
2. Наявність необхідних ролей
3. Стан підключення до інтернету
4. Логи у папці `logs/`

### Помилки з Google API

Перевірте:
1. Правильність шляху до файлу Service Account
2. Наявність доступу до таблиць/документів
3. Увімкненість необхідних API
4. Актуальність API ключів

### Проблеми з AI

Перевірте:
1. Стан локального сервера Ollama (якщо використовується)
2. Правильність API ключів (для OpenAI)
3. Наявність обраної моделі
4. Достатність системних ресурсів

### Повільна робота бота

Можливі причини:
1. Великий обсяг даних для обробки
2. Проблеми з інтернет-з'єднанням
3. Недостатність системних ресурсів
4. Необхідність очищення кешу
