# 🦖 Discord AI Assistant Bot - Godzilla
# Огляд

Discord AI Assistant Bot (Godzilla) - це потужний бот, розроблений для автоматизації роботи з документами, аналізу даних та підтримки операційної діяльності. Спеціально адаптований для потреб автоматизації документів та критично важливих організацій.

## 🎯 Основні можливості

### 🤖 AI асистент
- Природномовний аналіз даних
- Генерація звітів та рекомендацій
- Контекстна пам'ять для розмов

### 🔍 Розумний пошук
- Гнучкий пошук по всіх документах
- Фільтрація за датами, типами, пріоритетами
- Пагінація результатів

### 📄 Управління документами
- Робота з Google Sheets та Google Drive
- Читання різних форматів файлів (PDF, DOCX, TXT)
- AI-аналіз вмісту файлів

### 📊 Аналітика
- Статистика використання бота
- Аналіз даних з таблиць
- Експорт результатів у різних форматах

### ⚡ Операції
- Управління операційними процесами
- Координація між відділами
- Розвідувальні дані

### 🔒 Безпека
- Максимальний рівень захисту даних
- Контроль доступу через ролі Discord
- Rate limiting та валідація даних

## 🚀 Швидкий старт

1. **Клонування проекту**:
   ```bash
   git clone https://github.com/Dmitze/BotDiscordGodzilla.git
   cd BotDiscordGodzilla
   ```

2. **Встановлення залежностей**:
   ```bash
   npm install
   ```

3. **Налаштування змінних середовища**:
   ```bash
   cp .env.example .env
   # Відредагуйте .env файл з вашими налаштуваннями
   ```

4. **Запуск бота**:
   ```bash
   npm run deploy
   npm start
   ```

## 📋 Команди бота

### 🔍 Пошук та аналіз
```
/пошук запит:"персонал" тип_документа:"накази"
/розумний-пошук кількість_вище:100 ціна_нижче:1000
/ai запит:проаналізуй залишки та дай рекомендації
```

### 📄 Управління документами
```
/документи персонал список
/документи техніка додати назва:"Сервер"
/файли завантажити файл:document.pdf
```

### 📊 Аналітика
```
/статистика
/аналітика звіт тип:general
/продуктивність моніторинг
```

### ⚡ Операції
```
/операції ситуація поточний_стан
/операції завдання створити опис:"Моніторинг"
/операції координація зв'язок_з_керівництвом
```

## 🛡️ Безпека

Бот забезпечує максимальний рівень захисту даних:
- Підпис компонентів через HMAC-SHA256
- PII-маскування у логах
- Rate limiting для запобігання зловживанням
- Валідація всіх вхідних даних
