# Посібник користувача Discord AI Assistant Bot

## 🎯 Вступ

Цей посібник допоможе вам ефективно використовувати Discord AI Assistant Bot для автоматизації роботи з документами, аналізу даних та підтримки операційної діяльності.

## 🔐 Ролі та права доступу

Бот використовує систему ролей для контролю доступу:

- **Адміністратор** - повний доступ до всіх функцій
- **Бот-Користувач** - базові команди
- **Sheets-Доступ** - робота з Google Sheets
- **AI-Доступ** - AI функції
- **Експорт-Доступ** - експорт даних

Зверніться до адміністратора сервера для отримання необхідних ролей.

## 🔍 Команди пошуку

### Базовий пошук

Команда `/пошук` дозволяє шукати інформацію в документах:

```
/пошук запит:"ключове слово" тип_документа:"накази"
```

**Параметри:**
- `запит` - текст для пошуку (обов'язковий)
- `тип_документа` - фільтр за типом документа
- `дата_від` - пошук з певної дати
- `дата_до` - пошук до певної дати
- `відділ` - фільтр за відділом
- `пріоритет` - фільтр за пріоритетом
- `ліміт` - кількість результатів

### Розумний пошук

Команда `/розумний-пошук` дозволяє виконувати складніші пошукові запити:

```
/розумний-пошук кількість_вище:100 ціна_нижче:1000
```

**Параметри:**
- `кількість_вище` - мінімальна кількість
- `кількість_нижче` - максимальна кількість
- `ціна_вище` - мінімальна ціна
- `ціна_нижче` - максимальна ціна

## 🤖 AI команди

### AI асистент

Команда `/ai` дозволяє взаємодіяти з AI асистентом:

```
/ai запит:"проаналізуй персонал"
```

**Параметри:**
- `запит` - ваш запит до AI (обов'язковий)
- `контекст` - додатковий контекст для AI

### Приклади використання AI

1. **Аналіз даних:**
   ```
   /ai запит:"проаналізуй продажі за останній місяць"
   ```

2. **Генерація звітів:**
   ```
   /ai запит:"створи звіт по залишках на складі"
   ```

3. **Рекомендації:**
   ```
   /ai запит:"як оптимізувати логістику?"
   ```

## 📄 Робота з документами

### Команда /документи

Дозволяє працювати з документами:

```
/документи персонал список
```

**Підкоманди:**
- `додати` - додати новий документ
- `список` - показати список документів
- `оновити` - оновити існуючий документ
- `видалити` - видалити документ

### Команда /файли

Дозволяє працювати з файлами Google Drive:

```
/файли пошук запит:"назва файлу"
```

**Підкоманди:**
- `пошук` - пошук файлів
- `читати` - читання вмісту файлу
- `аналіз` - AI-аналіз файлу
- `звіт` - створення звіту за файлом

## 📊 Аналітика та статистика

### Команда /статистика

Показує статистику використання бота:

```
/статистика
```

### Команда /аналітика

Генерує аналітичні звіти:

```
/аналітика звіт тип:"загальний"
```

**Типи звітів:**
- `загальний` - загальна аналітика
- `пошук` - аналітика пошуку
- `команди` - аналітика команд
- `активність` - аналітика активності

## ⚡ Операційні команди

### Команда /операції

Управління операційними процесами:

```
/операції ситуація сектор:"А"
```

**Підкоманди:**
- `ситуація` - отримати інформацію про ситуацію
- `завдання` - управління завданнями
- `координація` - координація між відділами
- `аналітика` - розвідувальні дані

## 🛠️ Адміністративні команди

### Команда /статус

Показує статус системи:

```
/статус
```

### Команда /кеш

Управління кешем:

```
/кеш очистити тип:"всі"
```

**Типи кешу:**
- `пошук` - кеш пошуку
- `ai` - кеш AI
- `всі` - всі типи кешу

### Команда /допомога

Показує довідку:

```
/допомога категорія:"пошук"
```

**Категорії:**
- `пошук` - команди пошуку
- `ai` - AI команди
- `документи` - робота з документами
- `файли` - робота з файлами
- `аналітика` - аналітичні команди
- `операції` - операційні команди

## 🔒 Безпека

### Rate limiting

Бот має систему обмеження запитів для запобігання зловживанням:

- Пошук: 10 запитів за хвилину
- AI аналіз: 5 запитів за 2 хвилини
- Експорт: 3 запити за 5 хвилин

### Валідація даних

Всі вхідні дані автоматично перевіряються на:
- Довжину (макс. 500 символів для тексту)
- Наявність заборонених символів
- Формат дат

## 📤 Експорт даних

Більшість команд підтримують експорт результатів:

1. Виконайте команду пошуку або аналізу
2. Натисніть кнопку "Експорт" у відповіді
3. Оберіть формат експорту (Excel, CSV, PDF, DOCX)
4. Завантажте файл

## ❓ Часті питання

### Як отримати доступ до бота?

Зверніться до адміністратора вашого Discord сервера для отримання необхідних ролей.

### Які формати файлів підтримуються?

Бот підтримує роботу з:
- Google Sheets
- Google Docs
- PDF файли
- Microsoft Word документи
- Текстові файли

### Чи безпечне використання AI?

Так, бот забезпечує максимальний рівень безпеки:
- Дані не передаються третім сторонам (при використанні Ollama)
- Всі дані маскуються у логах
- Контроль доступу через ролі
