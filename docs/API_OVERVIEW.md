## 🚀 Огляд команд

| Команда | Опис | Основні параметри |
|---------|------|------------------|
| `/пошук` | Пошук у FTS/Google/гібрид | `запит`, `режим`, `фільтри` |
| `/ai` | AI асистент з підтримкою RAG | `запит`, `режим`, `макс_токенів` |
| `/док` | Довідник з документацією | `розділ`, `версія` |
| `/stats` | Статистика використання | `період`, `формат` |
| `/файл` | Керування файлами | `дія`, `шлях`, `параметри` |

## 🔍 Детальний опис команд

### 🔎 `/пошук`
Виконує пошук у зазначених джерелах з можливістю фільтрації.

**Параметри:**
- `запит` (обов'язковий) - Пошуковий запит
- `режим` - Режим пошуку: `fts`, `google`, `гібрид` (за замовчуванням: `гібрид`)
- `фільтри` - Додаткові фільтри пошуку (формат: `ключ:значення`)

### 🤖 `/ai`
Взаємодія з AI-асистентом з підтримкою контексту.

**Параметри:**
- `запит` (обов'язковий) - Запит до AI
- `режим` - Режим роботи: `стандарт`, `розгорнутий`, `стислий`
- `макс_токенів` - Максимальна кількість токенів у відповіді

### 📄 `/док`
Довідник з документацією до бота.

**Параметри:**
- `розділ` - Назва розділу документації
- `версія` - Версія документації (за замовчуванням: поточна)

### 📊 `/stats`
Отримання статистики використання.

**Параметри:**
- `період` - Період: `сьогодні`, `тиждень`, `місяць`, `рік`
- `формат` - Формат виводу: `текст`, `графік`, `таблиця`

## 💡 Приклади використання

```bash
# Пошук інформації
/пошук запит:"особовий склад 2025"
/пошук запит:"звіт про оперативну обстановку" режим:гібрид

# Робота з AI
/ai запит:"проаналізуй останні звіти"
/ai запит:"зроби висновок" режим:розгорнутий макс_токенів:1000

# Робота з документацією
/док розділ:"встановлення"
/док розділ:"налаштування" версія:2.0

# Перегляд статистики
/stats період:тиждень
/stats період:місяць формат:графік
```

## 🔒 Безпека

Усі інтерактивні компоненти захищені:
- Підписані через HMAC з встановленим TTL
- Валідація джерела та цілісності даних
- Обмеження частоти запитів (rate limiting)
