🚀 Кроки для запуску

1. Підготовка середовища

Створіть файл .env на основі env.example:

bash

Скопіюйте env.example в .env

cp env.example .env

Заповніть .env файл:

env

Discord Bot Configuration

BOT_TOKEN=your_discord_bot_token_here

Google Sheets Configuration

SHEET_ID=your_google_sheet_id_here
GOOGLE_API_KEY=your_google_api_key_here
APP_SCRIPT_URL=your_google_apps_script_url_here

OpenAI Configuration (для AI-функціоналу)

OPENAI_API_KEY=your_openai_api_key_here

Optional: Logging Configuration

LOG_LEVEL=info

Optional: Bot Configuration

BOT_PREFIX=!
GUILD_ID=your_guild_id_here

Optional: Performance Configuration

CACHE_TTL=300000
MAX_SEARCH_RESULTS=20
MAX_ANALYSIS_ROWS=50

bash

Встановлюємо залежності

npm install

Перевіряємо, що все встановлено

npm list

🔧 Вирішення проблем

Проблема: "Одна з обов'язкових ENV-змінних відсутня"

Рішення: Перевірте файл .env та заповніть всі необхідні змінні

Проблема: "Slash-команди не оновлюються"

Рішення: Запустіть node deploy-commands.js та перевірте права бота

Проблема: "AI-функції не працюють"

Рішення: 1. Перевірте OPENAI_API_KEY в .env 2. Запустіть node test-ai.js 3. Перевірте баланс на OpenAI рахунку

Проблема: "Помилка підключення до Google Sheets"

Рішення: 1. Перевірте SHEET_ID та GOOGLE_API_KEY 2. Переконайтеся, що Google Sheets API увімкнено 3. Перевірте права доступу до таблиці

📞 Підтримка

Якщо щось не працює:

1. Перевірте логи в папці logs/ 2. Використайте команду /статус 3. Запустіть тести: node test-ai.js 4. Перевірте налаштування в .env
