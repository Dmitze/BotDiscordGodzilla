📊 ГІД ПО КОМАНДІ STATISTICS

🎯 ОПИС КОМАНДИ

Команда /statistics дозволяє отримувати детальну статистику з Google Sheets з підтримкою складних формул, включаючи:
  • Підрахунок по парних/непарних стовпцях
  • Агрегацію даних по багатьох аркушах
  • Виконання складних формул типу ARRAY_CONSTRAIN + SUMPRODUCT
  • Групування та фільтрацію результатів
    • ---

    🚀 БАЗОВЕ ВИКОРИСТАННЯ

    Синтаксис команди:

    
/statistics operation:<тип_операції> sheets:<аркуші> [опції]

    Приклади використання:

    1. Простий підрахунок суми:

    
/statistics operation:sum sheets:"1Б БАК,2Б БАК,3Б БАК" range:"H6:AB6"

    2. Підрахунок по парних стовпцях:

    
/statistics operation:even_columns sheets:"1Б БАК,2Б БАК,РОЗВІД. рота" range:"H6:AB6"

    3. Складена формула:

    
/statistics operation:complex_formula sheets:"1Б БАК,2Б БАК" custom_formula:"ARRAY_CONSTRAIN(SUMPRODUCT(...))"
    ---

    📋 ПАРАМЕТРИ КОМАНДИ

    🔧 Обов'язкові параметри:

    | Параметр | Тип | Опис | Приклад | |----------|-----|------|---------| | operation | string | Тип операції | sum, even_columns, complex_formula | | sheets | string | Аркуші для аналізу | "1Б БАК,2Б БАК,3Б БАК" |

    ⚙️ Додаткові параметри:

    | Параметр | Тип | Опис | За замовчуванням | |----------|-----|------|------------------| | range | string | Діапазон даних | "H6:AB6" | | column_type | string | Тип стовпців | "all" | | group_by | string | Групування | - | | filters | JSON | Фільтри | {} | | custom_formula | string | Власна формула | - | ---

    🎯 ТИПИ ОПЕРАЦІЙ

    📊 Базові операції:

    1. sum - Сума

    bash
/statistics operation:sum sheets:"1Б БАК,2Б БАК" range:"H6:AB6"
    Результат: Загальна сума всіх числових значень у вказаному діапазоні.

    2. average - Середнє значення

    bash
/statistics operation:average sheets:"1Б БАК,2Б БАК" range:"H6:AB6"
    Результат: Середнє арифметичне всіх числових значень.

    3. count - Кількість

    bash
/statistics operation:count sheets:"1Б БАК,2Б БАК" range:"H6:AB6"
    Результат: Кількість непорожніх комірок з числовими значеннями.

    4. max - Максимум

    bash
/statistics operation:max sheets:"1Б БАК,2Б БАК" range:"H6:AB6"
    Результат: Найбільше числове значення у діапазоні.

    5. min - Мінімум

    bash
/statistics operation:min sheets:"1Б БАК,2Б БАК" range:"H6:AB6"
    Результат: Найменше числове значення у діапазоні.

    🔢 Розширені операції:

    6. even_columns - Парні стовпці

    bash
/statistics operation:even_columns sheets:"1Б БАК,2Б БАК,3Б БАК" range:"H6:AB6"
    Результат: Сума значень тільки з парних стовпців (H, J, L, N, ...).

    7. odd_columns - Непарні стовпці

    bash
/statistics operation:odd_columns sheets:"1Б БАК,2Б БАК,3Б БАК" range:"H6:AB6"
    Результат: Сума значень тільки з непарних стовпців (I, K, M, O, ...).

    8. complex_formula - Складена формула

    bash
/statistics operation:complex_formula sheets:"1Б БАК,2Б БАК" custom_formula:"ARRAY_CONSTRAIN(SUMPRODUCT(...))"
    Результат: Виконання власної складной формули Google Sheets. ---

    🔧 ФІЛЬТРИ ТА ГРУПУВАННЯ

    📋 Фільтри (JSON формат):

    bash

    📊 Групування:

    bash
/statistics operation:sum sheets:"1Б БАК,2Б БАК" group_by:"Тип підрозділу"
    ---

    📊 ТИПИ СТОВПЦІВ

    🔢 all - Всі стовпці (за замовчуванням)

    Аналізує всі стовпці у вказаному діапазоні.

    📈 even - Парні стовпці

    Аналізує тільки парні стовпці (H, J, L, N, P, R, T, V, X, Z, AB).

    📉 odd - Непарні стовпці

    Аналізує тільки непарні стовпці (I, K, M, O, Q, S, U, W, Y, AA). ---

    🎯 ПРАКТИЧНІ ПРИКЛАДИ

    📋 Приклад 1: Підрахунок особового складу

    bash
/statistics operation:sum sheets:"1Б БАК,2Б БАК,3Б БАК,РОЗВІД. рота" range:"H6:AB6" column_type:even
    Результат: Загальна кількість особового складу по парних стовпцях (наприклад, офіцери, сержанти).

    📊 Приклад 2: Середня кількість по підрозділах

    bash
/statistics operation:average sheets:"1Б БАК,2Б БАК,3Б БАК" range:"H6:AB6" group_by:"Тип підрозділу"
    Результат: Середня кількість особового складу по типах підрозділів.

    🔍 Приклад 3: Максимальна кількість

    bash
/statistics operation:max sheets:"1Б БАК,2Б БАК,3Б БАК,РОЗВІД. рота,Рота БАК" range:"H6:AB6"
    Результат: Найбільша кількість особового складу серед всіх підрозділів. ---

    🛠️ УСТРАНЕННЯ ПРОБЛЕМ

    ❌ Поширені помилки:

    1. "Формула занадто довга"

    Рішення: Розділіть формулу на менші частини або використовуйте простіші операції.

    2. "Непідтримувана функція"

    Рішення: Перевірте список підтримуваних функцій або зверніться до адміністратора.

    3. "Таймаут виконання"

    Рішення: Зменшіть кількість аркушів або розмір діапазону.

    4. "Немає доступу до аркуша"

    Рішення: Перевірте права доступу до Google Sheets.
