    🔧 Поширені проблеми

    🤖 Бот не відповідає

    Симптоми:
  • Бот не реагує на команди
  • Повідомлення "Interaction failed" або "Interaction has already been acknowledged"
  • Бот офлайн або не відповідає
    • Рішення: 1. Перевірте статус бота: 
    bash
   # Перевірка статусу процесу
   npm run status
   # Перегляд логів у реальному часі
   npm run logs
    2. Перезапустіть сервіс: 
    bash
   # Звичайний перезапуск
   npm restart
   # Повний перезапуск з очищенням кешу
   npm run rebuild
    3. Перевірка прав:
  • Переконайтеся, що бот має необхідні дозволи на сервері
  • Перевірте налаштування ролей та каналів
  • Переконайтеся, що бот доданий на сервер з правильними scope
    • 4. Перевірка підключення:
  • Переконайтеся, що сервер має вихід в інтернет
  • Перевірте налаштування фаєрволу
  • Спробуйте вимкнути VPN, якщо використовується

    • 🔍 Команди не працюють або не завантажуються

    Симптоми:
  • Команди не з'являються в списку
  • "Unknown interaction" помилка
  • Команди не реєструються
    • Рішення: 1. Deploy команди: 
    bash
   npm run deploy
    2. Перевірте конфігурацію: 
    env
   DISCORD_TOKEN=your_bot_token
   DISCORD_CLIENT_ID=your_client_id
   DISCORD_GUILD_ID=your_guild_id
    3. Перевірте права бота:
  • applications.commands scope
  • bot scope
  • Необхідні permissions

    • 📊 Google Sheets не працює

    Симптоми:
  • "Google Sheets API error"
  • "Permission denied"
  • Дані не завантажуються
    • Рішення: 1. Перевірте Service Account:
  • Файл google-credentials.json існує
  • Email сервісного акаунта має доступ до таблиці
    • 2. Перевірте налаштування: 
    env
   GOOGLE_SPREADSHEET_ID=your_spreadsheet_id
   GOOGLE_APPLICATION_CREDENTIALS=./google-credentials.json
    3. Надайте доступ до таблиці:
  • Відкрийте Google Sheets
  • Натисніть "Надати доступ"
  • Додайте email сервісного акаунта

    • 🤖 AI не працює

    Симптоми:
  • "AI service unavailable"
  • "OpenAI API error"
  • AI не відповідає
    • Рішення: 1. Перевірте API ключі: 
    env
   OPENAI_API_KEY=your_openai_key
   OLLAMA_HOST=http://localhost:11434
    2. Перевірте Ollama: 
    bash
   # Запуск Ollama
   ollama serve
   # Перевірка моделей
   ollama list
    3. Перевірте мережу:
  • Доступ до OpenAI API
  • Локальний доступ до Ollama

    ❓ Часті питання

    🤔 Як налаштувати бота?

    Відповідь: 1. Клонуйте репозиторій 2. Встановіть залежності: npm install 3. Скопіюйте .env.example в .env 4. Налаштуйте змінні середовища 5. Deploy команди: npm run deploy 6. Запустіть бота: npm start Детальна інструкція: SETUP.md

    🤔 Які команди доступні?

    Відповідь:
  • /залишки - підсумкові значення
  • /оновити - останні записи
  • /пошук - пошук за полями
  • /розумний-пошук - розширений пошук
  • /ai - AI-асистент
  • /файли - робота з файлами
  • /статистика - статистика бота
  • /допомога - довідка
    • Повний список: COMMANDS_REFERENCE.md

    🤔 Як використовувати AI-функції?

    Відповідь: 
    
/ai запит:знайди товари iPhone
/ai запит:проаналізуй залишки
/ai запит:створіть звіт по продажах
    Приклади: AI_EXAMPLES.md

    🤔 Як експортувати дані?

    Відповідь: 1. Виконайте пошук 2. Використайте команду /пошук-експортовано 3. Завантажте Excel файл Підтримувані формати: Excel (.xlsx), CSV, PDF, DOCX

    🤔 Як налаштувати права доступу?

    Відповідь: 1. Створіть ролі на Discord сервері:
  • Адміністратор
  • Бот-Користувач
  • Sheets-Доступ
  • AI-Доступ
  • Експорт-Доступ
    • 2. Призначте ролі користувачам 3. Налаштуйте права в конфігурації Деталі: SECURITY_GUIDE.md

    🤔 Як підвищити продуктивність?

    Відповідь: 1. Налаштуйте Redis кешування 2. Оптимізуйте запити до Google Sheets 3. Використовуйте rate limiting 4. Регулярно очищайте кеш: /очистити-кеш

    🤔 Як додати нові команди?

    Відповідь: 1. Створіть файл в папці commands/ 2. Додайте команду в deploy-commands.js 3. Інтегруйте в index.js 4. Deploy команди: npm run deploy Приклад: ARCHITECTURE.md ---

    🚨 Вирішення помилок

    ❌ "Interaction failed"

    Причина: Помилка обробки команди Рішення: 1. Перевірте логи: tail -f logs/bot.log 2. Перевірте конфігурацію 3. Перезапустіть бота

    ❌ "Rate limit exceeded"

    Причина: Перевищено ліміт запитів Рішення: 1. Дочекайтеся скидання ліміту 2. Зменшіть частоту запитів 3. Налаштуйте rate limiting

    ❌ "Permission denied"

    Причина: Недостатньо прав Рішення: 1. Перевірте ролі користувача 2. Налаштуйте права доступу 3. Зверніться до адміністратора

    ❌ "Google Sheets API error"

    Причина: Проблема з Google API Рішення: 1. Перевірте Service Account 2. Перевірте права доступу до таблиці 3. Перевірте API квоти

    ❌ "AI service unavailable"

    Причина: Проблема з AI сервісами Рішення: 1. Перевірте API ключі 2. Перевірте мережеве з'єднання 3. Перевірте статус AI сервісів

    ❌ "File not found"

    Причина: Файл не знайдено в Google Drive Рішення: 1. Перевірте назву файлу 2. Перевірте права доступу 3. Перевірте папку пошуку ---
