🔑 Discord Bot Setup

1. Obtaining Discord Token

1. Go to Discord Developer Portal 2. Click "New Application" and enter a name 3. In the "Bot" section, create a new bot 4. Copy the token (click "Copy" next to "Token") 5. Enable required Intents: ✅ Message Content Intent ✅ Server Members Intent ✅ Presence Intent ✅ Message Content

2. Adding Bot to Server

1. In the "OAuth2" "URL Generator" section, select: Permissions: Send Messages, Use Slash Commands, Embed Links, Attach Files, Read Message History 2. Generate URL and ask administrator to add bot to server

🔑 Obtaining API Keys

OpenAI API Key

1. Go to OpenAI Platform 2. Log in or create an account 3. Go to "API Keys" section 4. Click "Create new secret key" 5. Copy the key

🤖 Discord Bot Setup

1. Adding Bot to Server

1. In Discord Developer Portal, go to "OAuth2" "URL Generator" section 2. Select scopes: bot, applications.commands 3. Select permissions: Send Messages, Use Slash Commands, Embed Links, Attach Files, Read Message History 4. Copy the generated URL 5. Open URL in browser and add bot to your server

❗ Common Issues

1. "Invalid token"

  • Check Discord Bot Token correctness
  • Ensure token doesn't contain extra characters

    • 2. "Google Sheets API error"

  • Check Google API Key correctness
  • Enable Google Sheets API in Google Cloud Console
  • Check table access

    • 3. "OpenAI API error"

  • Check OpenAI API Key correctness
  • Ensure you have credits on OpenAI account

    • 4. "Command not found"

  • Restart bot after changing commands
  • Check that bot has rights to use slash commands

📞 Support
