📋 Повний список команд Discord Bot з AI

🤖 AI-команди (нові)

/ai-аналіз

Опис: Автоматичний AI-аналіз даних з таблиці Використання: /ai-аналіз Результат: Статистика, тренди, аномалії, рекомендації

/ai-пошук [запит]

Опис: Природномовний пошук за допомогою AI Використання: /ai-пошук запит:покажи товари дешевше 1000 грн Приклади:
  • /ai-пошук запит:знайди товари від постачальника "Компанія А"
  • /ai-пошук запит:покажи товари з кількістю більше 10
  • /ai-пошук запит:знайди найдорожчі товари

    • /ai-рекомендації

    Опис: AI-рекомендації на основі даних Використання: /ai-рекомендації Результат: Поради по оптимізації, покращенню ефективності

    /ai-звіт [тип]

    Опис: Створює розумний звіт Використання: /ai-звіт тип:general Типи звітів:
  • general - загальний звіт
  • inventory - звіт по залишках
  • sales - звіт по продажах
  • suppliers - звіт по постачальниках

    • 📊 Основні команди (існуючі)

    /залишки

    Опис: Показує підсумкові значення з таблиці Використання: /залишки Результат: Загальна вартість, кількість, ціна

    /оновити

    Опис: Показує останні 10 записів з таблиці Використання: /оновити Результат: Останні записи з таблиці

    /пошук [поле] [запит]

    Опис: Пошук за полями таблиці Використання: /пошук поле:назва запит:стол Поля для пошуку:
  • назва - Найменування
  • серія - Серійний номер
  • контрагент - Контрагент
  • кількість - Кількість
  • ціна - Ціна

    • /розумний-пошук

    Опис: Пошук за кількома полями Використання: /розумний-пошук номенклатура:стол контрагент:Компанія А Параметри:
  • номенклатура - Шукати за назвою товару
  • контрагент - Шукати за контрагентом
  • серія - Шукати за серійним номером
  • ціна_вище - Показувати товари дорожче цього значення
  • кількість_вище - Показувати товари з кількістю більше

    • /пошук-експортовано [поле] [запит]

    Опис: Експортує результати пошуку в Excel Використання: /пошук-експортовано поле:назва запит:стол Результат: Файл Excel з результатами пошуку

    /експорт

    Опис: Експортує всю таблицю в Excel Використання: /експорт Результат: Файл Excel з усією таблицею

    /help

    Опис: Показує список усіх доступних команд Використання: /help Результат: Список команд з описом

    💬 Текстові команди (існуючі)

    !додати [назва] [кількість]

    Опис: Додає новий запис через Google Apps Script Використання: !додати Стол 5 Результат: Новий запис додано до таблиці

    !експорт

    Опис: Експортується вся таблиця Використання: !експорт Результат: Файл Excel з усією таблицею

    🎯 Приклади використання

    AI-пошук (найкорисніші приклади):

    
/ai-пошук запит:покажи товари дешевше 1000 грн
/ai-пошук запит:знайди товари від постачальника "ООО Рога і Копита"
/ai-пошук запит:покажи товари з кількістю більше 10
/ai-пошук запит:знайди найдорожчі товари
/ai-пошук запит:покажи товари з назвою що містить "компьютер"
/ai-пошук запит:знайди товари з серійним номером що починається з "SN"

    Комбінований пошук:

    
/ai-пошук запит:покажи товари дешевше 500 грн з кількістю більше 5
/ai-пошук запит:знайди товари від постачальника "Компанія А" з ціною вище 2000

    Звичайний пошук:

    
/пошук поле:назва запит:стол
/пошук поле:контрагент запит:Компанія А
/пошук поле:ціна запит:1000

    Розумний пошук:

    
/розумний-пошук номенклатура:стол ціна_вище:500
/розумний-пошук контрагент:Компанія А кількість_вище:10

    🔧 Технічні деталі

    Обмеження:

  • AI-пошук: максимум 20 результатів
  • AI-аналіз: перші 50 рядків даних
  • Експорт файлів: автоматичне видалення через 10 секунд

    • Вимоги:

  • OpenAI API ключ для AI-функцій
  • Google Sheets API для роботи з таблицями
  • Discord Bot Token для роботи бота

    • Кешування:

  • Результати пошуку кешуються на 5 хвилин
  • Можна експортувати кешовані результати

🆘 Допомога

Якщо команди не працюють:

1. Перевірте права бота на сервері 2. Переконайтеся, що всі API ключі налаштовані 3. Перевірте логи в папці logs/

Для AI-функцій:

1. Переконайтеся, що є OpenAI API ключ 2. Запустіть тест: node test-ai.js 3. Перевірте баланс на OpenAI рахунку

Для Google Sheets:

1. Перевірте доступ до таблиці 2. Переконайтеся, що Google Sheets API увімкнено 3. Перевірте правильність SHEET_ID --- 💡 Порада: Почніть з команди /help для ознайомлення з усіма можливостями бота!
