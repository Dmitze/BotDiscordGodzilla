🎯 Огляд

Discord AI Assistant Bot (Godzilla) - це інноваційний бот, розроблений для автоматизації роботи з документами, аналізу даних та підтримки операційної діяльності. Спеціально адаптований для потреб ЗСУ та критично важливих організацій. Бот інтегрується з Google Sheets, Google Drive, Discord та AI сервісами (OpenAI, Ollama) для надання потужних інструментів аналізу та автоматизації. ---

    🏗️ Архітектура

    Основні компоненти

    1. Ядро бота (src/core/Bot.ts)
  • Головний клас бота
  • Ініціалізація та управління сервісами
  • Обробка подій Discord
    • 2. Команди (src/commands/)
  • Модульна система команд
  • Валідація вхідних даних
  • Структурне логування
    • 3. Сервіси (src/services/)
  • GoogleService - робота з Google API
  • AIService - інтеграція з AI моделями
  • CacheService - кешування даних
  • MetricsService - збір метрик
    • 4. Пошук (src/search/)
  • Гібридний пошук (FTS + векторний)
  • Індексація документів
  • RAG пайплайн
    • 5. RAG (src/rag/)
  • Пошук релевантних фрагментів
  • Підготовка контексту
  • Генерація відповідей

    • Технологічний стек

  • Мова: TypeScript 5.0+
  • Платформа: Node.js 20.x (LTS)
  • Фреймворк: Discord.js 14.x
  • База даних: SQLite3 (FTS5), Redis (кеш)
  • AI/ML: Ollama (локально), OpenAI API (опційно)
  • Інтеграції: Google Sheets API, Google Drive API
  • Моніторинг: Prometheus + Grafana
    • ---

    ⚙️ Встановлення та налаштування

    Системні вимоги

  • Node.js 18+
  • Git
  • Docker (опційно)
  • Google Cloud обліковий запис
  • Discord Developer обліковий запис

    • Швидкий старт

    1. Клонування проекту 
    bash
   git clone https://github.com/Dmitze/BotDiscordGodzilla.git
   cd BotDiscordGodzilla
    2. Встановлення залежностей 
    bash
   npm install
    3. Налаштування змінних середовища 
    bash
   cp .env.example .env
   # Відредагуйте .env файл з вашими налаштуваннями
    4. Налаштування Discord бота
  • Перейдіть на Discord Developer Portal
  • Створіть новий додаток та бота
  • Скопіюйте токен
  • Увімкніть необхідні Intents
    • 5. Налаштування Google API
  • Створіть проект у Google Cloud Console
  • Увімкніть Google Sheets API та Google Drive API
  • Створіть Service Account та завантажте JSON ключ
    • 6. Запуск бота 
    bash
   npm run deploy
   npm start

    🔐 Безпека

    Механізми захисту

    1. Підпис компонентів
  • Усі кнопки та селектори підписуються через HMAC-SHA256
  • TTL для кожного компоненту (за замовчуванням 15 хв)
  • Відмова у доступі до прострочених компонентів
    • 2. Робота з даними
  • PII-маскування у логах
  • Шифрування конфіденційних даних
  • Обмежений доступ до API ключів
    • 3. Захист API
  • Rate limiting
  • Валідація вхідних даних
  • Обробка помилок без розголошення деталей

    • Ролі та права доступу

  • Адміністратор - повний доступ до всіх функцій
  • Бот-Користувач - базові команди
  • Sheets-Доступ - робота з Google Sheets
  • AI-Доступ - AI функції
  • Експорт-Доступ - експорт даних
    • ---

    🦙 Локальний AI (Ollama)

    Переваги

  • Дані не залишають інфраструктуру
  • Відсутність обмежень API ключів
  • Можливість офлайн-роботи

    • Встановлення

    1. Встановлення Ollama 
    bash
   # Для Windows/Linux/macOS
   curl -fsSL https://ollama.com/install.sh | sh
    2. Завантаження моделі 
    bash
   ollama run llama3.1
    3. Налаштування бота Додайте до вашого .env файлу: 
    
   AI_PROVIDER=ollama
   OLLAMA_BASE_URL=http://localhost:11434

    📊 Метрики та моніторинг

    Prometheus метрики

    Бот збирає різні метрики для моніторингу продуктивності:
  • Кількість команд
  • Час виконання запитів
  • Попадання в кеш
  • Помилки
  • Використання пам'яті

    • Health checks

    Регулярна перевірка стану системи:
  • Кожні 30 секунд
  • Моніторинг пам'яті кожну хвилину
  • Автоматичний перезапуск при перевищенні лімітів

    • Логування

    Централізоване логування з різними рівнями:
  • error - критичні помилки
  • warn - попередження
  • info - інформаційні повідомлення
  • debug - налагоджувальна інформація

    👨‍💻 Розробка

    Структура проекту

    
src/
├── api/          # API документація
├── chat/         # Чат-функціонал
├── commands/     # Команди бота
├── components/   # Компоненти інтерфейсу
├── config/       # Конфігурація
├── core/         # Ядро бота
├── i18n/         # Локалізація
├── nlp/          # NLP функції
├── parsers/      # Парсери файлів
├── rag/          # RAG пайплайн
├── scripts/      # Скрипти
├── search/       # Пошукові функції
├── security/     # Безпека
├── services/     # Сервіси
├── tests/        # Тести
├── types/        # Типи TypeScript
├── ui/           # UI компоненти
├── utils/        # Утиліти
└── workspace/    # Робоча область

    Додавання нової команди

    1. Створіть файл команди у src/commands/ 2. Наслідуйтесь від BaseCommand 3. Реалізуйте методи execute та getCommandData 4. Зареєструйте команду в CommandManager

  • E2E тести

npm test
npm run test:coverage
