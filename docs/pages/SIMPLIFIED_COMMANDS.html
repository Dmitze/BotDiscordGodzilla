Спрощена структура команд

Цей документ описує спрощену структуру команд для Discord бота, зосереджуючись на трьох основних функціях: 1. AI Асистент 2. Пошук у Google Drive 3. Розпізнавання тексту OCR

Огляд

Спрощена структура команд зменшує складність, надаючи лише необхідну функціональність через чистий, інтуїтивний інтерфейс. Користувачі взаємодіють з ботом через одну команду /bot з необов'язковими параметрами.

Команди

Основна команда: /bot

Основна команда, яка забезпечує доступ до всієї функціональності бота. Параметри:
  • action (необов'язково): Вказує функцію для використання
  • ai: AI Асистент
  • search: Пошук у Google Drive
  • ocr: Розпізнавання тексту OCR
  • query (необов'язково): Запит або підказка для обраної дії
    • Приклади: 
    
/bot action:ai query:"Яка столиця Франції?"
/bot action:search query:"звіт про проект"
/bot action:ocr

    Функціональність

    1. AI Асистент

    AI Асистент забезпечує можливості обробки природної мови, використовуючи моделі Ollama (локальні) або OpenAI (зовнішні). Особливості:
  • Розуміння природної мови
  • Відповіді з урахуванням контексту
  • Багатоциклові розмови
  • Механізми відновлення між провайдерами
    • Аспекти конфіденційності:
  • Ollama обробляє дані локально (рекомендовано для конфіденційної інформації)
  • OpenAI надсилає дані на зовнішні сервери (потужніший, але менш приватний)
  • Вибір провайдера на основі каналів дозволяє елементи керування конфіденційністю по каналах

    • 2. Пошук у Google Drive

    Функціональність пошуку для файлів Google Drive в межах налаштованої області папок. Особливості:
  • Пошук за назвою файлу та вмістом
  • Фільтр за типом файлу
  • Прямі посилання на файли Google Drive
  • Результати обмежені налаштованою папкою та підпапками

    • 3. Розпізнавання тексту OCR

    Оптичне розпізнавання символів для вилучення тексту з зображень. Особливості:
  • Підтримка кількох провайдерів OCR:
  • Tesseract (локальний, офлайн)
  • Google Vision (хмарний)
  • Вимкнено (без OCR)
  • Автоматичне визначення мови
  • Підтримка кількох мов (англійська, українська)

    • Компоненти UI

    Спрощений UI надає лише необхідні кнопки: 1. 🤖 AI Асистент - Доступ до функціональності чату AI 2. 🔍 Пошук у Google Drive - Пошук файлів у Google Drive 3. 📝 Розпізнавання тексту OCR - Вилучення тексту з зображень 4. ❌ Закрити - Закрити поточну взаємодію 5. Навігація - Навігація по сторінках для довгого вмісту

    Конфігурація

    Змінні середовища

    Ключові змінні середовища для спрощеної функціональності: 
    

    Конфігурація AI
    
AI_PROVIDER=ollama
OLLAMA_HOST=http://localhost:11434
OLLAMA_MODEL=llama3.2

    Конфігурація Google API
    
GOOGLE_APPLICATION_CREDENTIALS=./secrets/google-credentials.json
GOOGLE_DRIVE_FOLDER_ID=your-folder-id

    Конфігурація OCR
    
OCR_PROVIDER=tesseract
TESSERACT_LANGS=eng+ukr

    Конфіденційність та безпека

    Обробка даних

    1. Локальна обробка: Ollama обробляє всі дані локально, забезпечуючи максимальну конфіденційність 2. Елементи керування на основі каналів: Різні провайдери AI можна налаштувати для різних каналів Discord 3. Захист PII: Особисту ідентифікаційну інформацію автоматично маскують 4. Мінімальна передача даних: Лише необхідні дані надсилаються зовнішнім сервісам

    Найкращі практики

    1. Використовуйте Ollama для обробки конфіденційних даних 2. Налаштуйте окремі канали для різних вимог конфіденційності 3. Регулярно переглядайте та перевіряйте журнали доступу до даних 4. Зберігайте облікові дані в безпеці та регулярно їх ротуйте

    Вирішення проблем

    Поширені проблеми

    1. Погана якість відповідей AI
  • Перевірте, чи Ollama працює та доступний
  • Переконайтесь, що модель завантажена (ollama list)
  • Розгляньте можливість переходу на OpenAI для складних запитів
  • Переконайтесь, що для Ollama достатньо системних ресурсів
    • 2. Пошук у Google Drive не працює
  • Перевірте правильність облікових даних Google API
  • Переконайтесь, що обліковий запис сервісу має доступ до папки Drive
  • Переконайтесь, що ID папки правильно налаштовано
  • Перевірте, чи в області API включено доступ до Drive
    • 3. OCR не розпізнає текст
  • Перевірте правильність налаштування провайдера OCR
  • Для Tesseract переконайтесь, що мовні пакети встановлено
  • Для Google Vision перевірте облікові дані API та оплату
  • Спробуйте різні формати зображень та якість

    • Перевірка здоров'я

    Використовуйте вбудовані кінцеві точки перевірки здоров'я для моніторингу стану сервісу: 
    

    Перевірка здоров'я сервісу AI
    
GET /health/ai

    Перевірка здоров'я сервісу Google
    
GET /health/google

    Загальне здоров'я бота
    
GET /health

    Обслуговування

    Регулярні завдання

    1. Оновлення моделей Ollama 
    
   ollama pull llama3.2
    2. Ротація облікових даних Google API
  • Згенеруйте новий ключ облікового запису сервісу
  • Оновіть GOOGLE_APPLICATION_CREDENTIALS
  • Перевірте дозволи доступу
    • 3. Моніторинг здоров'я сервісу
  • Регулярно перевіряйте кінцеві точки здоров'я
  • Переглядайте журнали помилок на наявність повторюваних проблем
  • Відстежуйте використання ресурсів (ЦП, пам'ять, диск)

    • Перезапуск сервісу

    Щоб перезапустити сервіси бота: 
    bash

    Зупинити сервіси
    
npm run stop

    Запустити сервіси
    
npm run start

    Розширена конфігурація

    Провайдери AI на основі каналів

    Налаштуйте різних провайдерів AI для різних каналів: 
    

    У вашому обробнику команд
    
aiService.setChannelProvider('channel-id-1', 'ollama');
aiService.setChannelProvider('channel-id-2', 'openai');
    Це дозволяє:
  • Приватним каналам використовувати локальну обробку Ollama
  • Публічним каналам використовувати потужніший OpenAI
  • Тонке керування конфіденційністю даних

Налаштування UI

Спрощені компоненти UI можна налаштувати в src/ui/simpleComponents.ts: 1. Змінити мітки кнопок та стилі 2. Налаштувати поведінку пагінації 3. Налаштувати параметри розбиття тексту 4. Додати нові кнопки дій (зберігаючи простоту)
