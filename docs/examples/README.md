# Examples

This directory contains example scripts demonstrating various features of the Discord AI Assistant Bot.

## Available Examples

### Markdown Rendering Example
- File: [markdown-rendering-example.ts](markdown-rendering-example.ts)
- Demonstrates the markdown rendering capabilities of the bot
- Shows how to render text, images, and validate markdown

### Ollama Example
- File: [ollama-example.ts](ollama-example.ts)
- Demonstrates how to use the Ollama service
- Shows conversation history management and model interactions

## Usage

To run any example, use:

```bash
ts-node docs/examples/example-file.ts
```

Make sure you have the required environment variables set up as described in the main documentation.
