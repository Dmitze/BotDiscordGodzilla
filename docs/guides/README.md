# 🤖 Discord AI Assistant Bot для ЗСУ

**Оновлено: 28.07.2025**

Сучасний Discord бот з AI функціоналом для роботи з військовими документами ЗСУ. Побудований на модульній архітектурі з інтеграцією Google Sheets, AI сервісів та розширеними можливостями кешування.

## 🚀 **ОСОБЛИВОСТІ**

### **🏗️ Архітектура**

- **Модульна система** - чітке розділення відповідальності
- **Сервісна архітектура** - незалежні компоненти
- **Централізована обробка помилок** - надійна робота
- **Кешування** - висока продуктивність
- **Метрики** - детальний моніторинг

### **🔧 Функціональність**

- **Гнучкий пошук** - пошук по будь-яким критеріям
- **AI асистент** - аналіз та допомога з документами
- **Управління документами** - робота з різними типами документів
- **Аналітика** - звіти та статистика
- **Операції** - управління військовими операціями

## 📋 **КОМАНДИ**

### **🔍 Пошук**

```
/пошук запит: "особовий склад" тип_документа: "накази" дата_від: "01.01.2025" дата_до: "31.12.2025" підрозділ: "1-й батальйон" пріоритет: "високий" ліміт: 20
```

- **Гнучкий пошук** по всіх документах
- **Фільтрація** за типом, датою, підрозділом, пріоритетом
- **Кешування** результатів для швидкості

### **🤖 AI Асистент**

```
/ai запит: "Проаналізуй особовий склад" контекст: "Дані за 2025 рік" режим: "аналіз"
```

- **5 режимів роботи**: загальний, аналіз, звіт, пояснення, рекомендації
- **Контекстні дані** з Google Sheets
- **Кешування** AI відповідей

### **📄 Документи**

```
/документи особовий-склад дія: "пошук" запит: "сержанти"
/документи техніка дія: "обслуговування"

/документи операції дія: "планування"
/документи накази дія: "створення"
```

- **5 категорій**: особовий-склад, техніка, матеріали, операції, накази
- **14 дій** для кожної категорії
- **Інтеграція** з AI для аналізу

### **📊 Аналітика**

```
/аналітика звіт тип: "особовий-склад" період: "місяць"
/аналітика статистика категорія: "техніка"

/аналітика порівняння період1: "січень" період2: "лютий"
```

- **Звіти** по всіх категоріях
- **Статистика** та тренди
- **Прогнозування** на основі AI
- **Порівняння** періодів

## 🛠️ **ВСТАНОВЛЕННЯ**

### **Вимоги**

- Node.js 18+
- Discord Bot Token
- Google Sheets API
- OpenAI API або Ollama
- Redis (опціонально)

### **Кроки встановлення**

1. **Клонування репозиторію**

```bash
git clone https://github.com/your-username/BotDiscordGodzilla.git
cd BotDiscordGodzilla
```

2. **Встановлення залежностей**

```bash
npm install
```

3. **Налаштування змінних середовища**

```bash
cp env.example .env
```

4. **Редагування .env файлу**

```env
# Discord
DISCORD_TOKEN=your_discord_token
DISCORD_CLIENT_ID=your_client_id
DISCORD_GUILD_ID=your_guild_id

# Google
GOOGLE_SPREADSHEET_ID=your_spreadsheet_id
GOOGLE_API_KEY=your_api_key
GOOGLE_APPLICATION_CREDENTIALS=path/to/credentials.json

# AI
OPENAI_API_KEY=your_openai_key
OLLAMA_HOST=http://localhost:11434

# Redis (опціонально)
REDIS_ENABLED=true
REDIS_HOST=localhost
REDIS_PORT=6379
```

5. **Реєстрація команд**

```bash
npm run deploy-commands
```

6. **Запуск бота**

```bash
npm start
```

## 🏗️ **АРХІТЕКТУРА**

### **Структура проекту**

```
src/
├── core/                    # Основні класи
│   ├── Bot.js              # Центральний клас бота
│   ├── CommandManager.js   # Управління командами
│   ├── ServiceManager.js   # Управління сервісами
│   ├── EventManager.js     # Обробка Discord подій
│   └── ErrorHandler.js     # Централізована обробка помилок
├── services/               # Бізнес-логіка
│   ├── AIService.js        # AI функціонал
│   ├── GoogleService.js    # Google APIs
│   ├── CacheService.js     # Кешування
│   ├── MetricsService.js   # Метрики та моніторинг
│   └── SchedulerService.js # Планувальник завдань
├── commands/               # Discord команди
│   ├── search.js           # Гнучкий пошук
│   ├── aiAssistant.js      # AI асистент
│   ├── documents.js        # Управління документами
│   ├── analytics.js        # Аналітика
│   └── operations.js       # Операції
├── config/                 # Конфігурація
│   └── Config.js           # Централізована конфігурація
├── utils/                  # Утиліти
│   └── logger.js           # Розширений логер
└── tests/                  # Тести
    ├── unit/               # Unit тести
    ├── integration/        # Інтеграційні тести
    └── load/               # Навантажувальні тести
```

### **Ключові компоненти**

#### **Bot.js**

- Централізоване управління всіма компонентами
- Graceful shutdown
- Статистика та моніторинг

#### **CommandManager.js**

- Завантаження та валідація команд
- Обробка Discord interactions
- Перевірка прав доступу

#### **ServiceManager.js**

- Ініціалізація сервісів
- Управління життєвим циклом
- Доступ до сервісів

#### **ErrorHandler.js**

- Централізована обробка помилок
- Класифікація помилок
- Логування та відновлення

## 🔧 **РОЗРОБКА**

### **Додавання нової команди**

1. **Створення файлу команди**

```javascript
// src/commands/newCommand.js
const { SlashCommandBuilder } = require('discord.js');

module.exports = {
  data: new SlashCommandBuilder().setName('нова-команда').setDescription('Опис команди'),

  permissions: {
    roles: ['Бот-Користувач'],
  },

  async execute(interaction, bot) {
    // Логіка команди
  },
};
```

2. **Реєстрація команди**

```bash
npm run deploy-commands
```

### **Додавання нового сервісу**

1. **Створення сервісу**

```javascript
// src/services/NewService.js
class NewService {
  constructor(bot) {
    this.bot = bot;
  }

  async initialize() {
    // Ініціалізація
  }

  async shutdown() {
    // Завершення роботи
  }
}

module.exports = NewService;
```

2. **Реєстрація в ServiceManager**

```javascript
// src/core/ServiceManager.js
this.services.set('new', new NewService(this.bot));
```
