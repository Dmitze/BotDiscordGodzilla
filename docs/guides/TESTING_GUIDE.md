# 🧪 РУКОВОДСТВО ПО ТЕСТИРОВАНИЮ DISCORD БОТА

## 📋 ПРЕДВАРИТЕЛЬНАЯ ПОДГОТОВКА

### 1. Настройка переменных окружения

Создайте файл `.env` в корне проекта на основе `src/config/environment/env.example`:

```bash
# Скопируйте пример
cp src/config/environment/env.example .env

# Отредактируйте .env файл
nano .env
```

**Обязательные переменные для тестирования:**

```env
# Discord настройки
DISCORD_TOKEN=your_discord_bot_token_here
DISCORD_CLIENT_ID=your_discord_client_id_here
DISCORD_GUILD_ID=your_guild_id_here

# Google настройки (для команд поиска)
GOOGLE_SPREADSHEET_ID=your_spreadsheet_id_here
GOOGLE_API_KEY=your_google_api_key_here

# AI настройки (для AI ассистента)
AI_PROVIDER=openai
OPENAI_API_KEY=your_openai_api_key_here
```

### 2. Сборка проекта

```bash
# Установка зависимостей
npm install

# Сборка TypeScript
npm run build
```

### 3. Регистрация команд в Discord

```bash
# Регистрация команд
npm run deploy:commands
```

## 🚀 ЗАПУСК БОТА

### 1. Запуск в режиме разработки

## 🧪 ТЕСТИРОВАНИЕ КОМАНД

### 1. Базовые команды поиска

**Команда: `/пошук`**
```
Тест 1: Простой поиск
- Введите: /пошук запит:тест
- Ожидаемый результат: Список результатов из Google Sheets

Тест 2: Поиск с фильтрами
- Введите: /пошук запит:документ дата_від:2024-01-01 дата_до:2024-12-31
- Ожидаемый результат: Отфильтрованные результаты по датам
```

**Команда: `/розширений_пошук`**
```
Тест 1: Расширенный поиск
- Введите: /розширений_пошук номенклатура:товар ціна_від:100 ціна_до:1000
- Ожидаемый результат: Результаты с фильтрацией по цене

Тест 2: Сортировка
- Введите: /розширений_пошук сортування:ціна порядок:desc
- Ожидаемый результат: Результаты отсортированные по цене
```

## 🔍 ПРОВЕРКА РАБОТЫ

### 1. Проверка подключения к Discord

После запуска бота вы должны увидеть:
```
🤖 Discord бот успішно ініціалізовано
🤖 Бот [BotName] готовий до роботи
```

### 2. Проверка регистрации команд

В Discord сервере команды должны появиться в списке slash-команд.

### 3. Проверка работы с Google Sheets

Выполните команду `/пошук` и убедитесь, что:
- Бот получает данные из Google Sheets
- Результаты отображаются корректно
- Кеширование работает (второй запрос должен быть быстрее)

### 4. Проверка AI функциональности

Выполните команду `/ai_асистент` и убедитесь, что:
- AI отвечает на запросы
- Ответы релевантны
- Нет ошибок подключения к AI сервису

## 🐛 ОТЛАДКА ПРОБЛЕМ

### 1. Проблемы с подключением к Discord

**Симптомы:** Бот не подключается к Discord
**Решение:**
- Проверьте правильность `DISCORD_TOKEN`
- Убедитесь, что бот добавлен на сервер
- Проверьте права бота

### 2. Проблемы с Google Sheets

**Симптомы:** Команды поиска не работают
**Решение:**
- Проверьте `GOOGLE_API_KEY`
- Убедитесь, что `GOOGLE_SPREADSHEET_ID` правильный
- Проверьте доступ к таблице

### 3. Проблемы с AI

**Симптомы:** AI ассистент не отвечает
**Решение:**
- Проверьте `OPENAI_API_KEY`
- Убедитесь, что есть баланс на OpenAI
- Проверьте настройки модели

### 4. Проблемы с командами

**Симптомы:** Команды не регистрируются
**Решение:**
```bash
# Перерегистрируйте команды
npm run deploy:commands

# Перезапустите бота
npm run dev
```
