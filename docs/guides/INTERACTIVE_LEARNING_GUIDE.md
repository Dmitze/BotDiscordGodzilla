# 🎓 Інтерактивний навчальний гід Discord AI Assistant Bot

## 📚 Огляд

Цей інтерактивний гід допоможе вам освоїти Discord AI Assistant Bot v2.3.0 через практичні завдання, тести та реальні сценарії використання.

---

## 🎯 Структура навчання

### 📖 Рівні навчання:

1. **🌱 Початківець** - базові команди та функції
2. **🌿 Середній** - розширені можливості та AI
3. **🌳 Досвідчений** - технічні деталі та розробка

### ⏱️ Тривалість:

- **Початківець:** 2-3 години
- **Середній:** 4-5 годин
- **Досвідчений:** 6-8 годин

## 🌱 РІВЕНЬ 1: ПОЧАТКІВЕЦЬ

### 📋 Модуль 1: Знайомство з ботом

#### 🎯 Завдання 1.1: Перший контакт

**Мета:** Навчитися взаємодіяти з ботом

**Кроки:**

1. Запустіть Discord та знайдіть канал з ботом
2. Введіть команду: `/допомога`
3. Вивчіть відповідь бота
4. Спробуйте різні категорії довідки

**Очікуваний результат:**

- Розуміння основних команд
- Вміння навігувати по довідці
- Звикання до інтерфейсу бота

**✅ Критерії успіху:**

- [ ] Команда `/допомога` виконується успішно
- [ ] Розумієте структуру довідки
- [ ] Можете знайти потрібну інформацію

---

#### 🎯 Завдання 1.2: Базові команди пошуку

**Мета:** Освоїти основні команди пошуку

**Кроки:**

1. Виконайте команду `/залишки`
2. Виконайте команду `/оновити`
3. Спробуйте команду `/пошук` з різними параметрами:
   ```
   /пошук поле:найменування запит:iPhone
   /пошук поле:контрагент запит:Apple
   /пошук поле:ціна запит:1000
   ```

**Практичні завдання:**

- Знайдіть товари з ціною вище 5000 грн
- Знайдіть товари від конкретного постачальника
- Подивіться останні 10 записів

**✅ Критерії успіху:**

- [ ] Розумієте різницю між командами
- [ ] Можете формулювати пошукові запити
- [ ] Отримуєте корисні результати

---

### 📋 Модуль 2: Робота з даними

#### 🎯 Завдання 2.1: Розумний пошук

**Мета:** Освоїти розширені можливості пошуку

**Кроки:**

1. Виконайте команду `/розумний-пошук` з різними критеріями:
   ```
   /розумний-пошук номенклатура:iPhone ціна_вище:500
   /розумний-пошук контрагент:Apple кількість_вище:10
   /розумний-пошук серія:IPH кількість_вище:5
   ```

**Практичні завдання:**

- Знайдіть товари iPhone з кількістю більше 5 та ціною вище 1000
- Знайдіть товари від Apple з кількістю більше 10
- Створіть комбінований пошук за вашими критеріями

**✅ Критерії успіху:**

- [ ] Розумієте логіку комбінованого пошуку
- [ ] Можете використовувати фільтри
- [ ] Отримуєте точні результати

---

#### 🎯 Завдання 2.2: Експорт даних

**Мета:** Навчитися експортувати дані

**Кроки:**

1. Виконайте пошук за будь-яким критерієм
2. Експортуйте результати командою `/пошук-експортовано`
3. Завантажте та відкрийте Excel файл

**Практичні завдання:**

- Експортуйте всі товари iPhone
- Експортуйте товари з ціною вище 2000
- Створіть звіт по конкретному постачальнику

**✅ Критерії успіху:**

- [ ] Можете експортувати дані
- [ ] Розумієте формат Excel файлу
- [ ] Можете працювати з експортованими даними

## 🌿 РІВЕНЬ 2: СЕРЕДНІЙ

### 📋 Модуль 3: AI-функціонал

#### 🎯 Завдання 3.1: Природномовні запити

**Мета:** Освоїти AI-асистента

**Кроки:**

1. Спробуйте базові AI-запити:

   ```
   /ai запит:знайди товари iPhone
   /ai запит:проаналізуй залишки на складі
   /ai запит:покажи статистику по продажах
   ```

2. Експериментуйте з контекстом:
   ```
   /ai запит:проаналізуй тренди контекст:за останні 3 місяці
   /ai запит:знайди дешеві альтернативи контекст:до 500 грн
   ```

**Практичні завдання:**

- Запитайте AI про найпопулярніші товари
- Попросіть створити звіт по продажах
- Запитайте рекомендації для закупівель

**✅ Критерії успіху:**

- [ ] Розумієте як формулювати AI-запити
- [ ] Можете використовувати контекст
- [ ] Отримуєте корисні AI-відповіді

---

#### 🎯 Завдання 3.2: Контекстна пам'ять

**Мета:** Освоїти роботу з контекстом

**Кроки:**

1. Почніть розмову з AI:

   ```
   /ai запит:привіт, я хочу проаналізувати наші продажі
   ```

2. Продовжіть розмову:

   ```
   /ai запит:покажи найкращі товари
   ```

3. Уточніть деталі:
   ```
   /ai запит:а що з цінами на них?
   ```

**Практичні завдання:**

- Проведіть повну розмову з AI про аналіз даних
- Попросіть AI створити план дій
- Запитайте детальні пояснення

**✅ Критерії успіху:**

- [ ] Розумієте як працює контекстна пам'ять
- [ ] Можете вести осмислену розмову з AI
- [ ] Отримуєте релевантні відповіді

### 📋 Модуль 4: Робота з файлами

#### 🎯 Завдання 4.1: Пошук файлів

**Мета:** Навчитися працювати з Google Drive

**Кроки:**

1. Знайдіть файли командою `/файли`:

   ```
   /файли дія:пошук запит:звіт
   /файли дія:пошук запит:документ
   ```

2. Експериментуйте з фільтрами:
   ```
   /файли дія:пошук запит:звіт папка:123456789
   ```

**Практичні завдання:**

- Знайдіть всі PDF файли
- Знайдіть документи за останній місяць
- Створіть список важливих файлів

**✅ Критерії успіху:**

- [ ] Можете шукати файли в Google Drive
- [ ] Розумієте як використовувати фільтри
- [ ] Знаходите потрібні файли

---

#### 🎯 Завдання 4.2: Читання та аналіз файлів

**Мета:** Освоїти роботу з вмістом файлів

**Кроки:**

1. Прочитайте файл:

   ```
   /файли дія:читати запит:звіт_2024.pdf
   ```

2. Проаналізуйте файл:

   ```
   /файли дія:аналіз запит:звіт_2024.pdf тип:summary
   ```

3. Створіть звіт:
   ```
   /файли дія:звіт запит:звіт_2024.pdf формат:pdf
   ```

**Практичні завдання:**

- Проаналізуйте кілька різних типів файлів
- Порівняйте результати аналізу
- Створіть звіти в різних форматах

**✅ Критерії успіху:**

- [ ] Можете читати різні типи файлів
- [ ] Розумієте результати AI-аналізу
- [ ] Можете створювати звіти

### 📋 Модуль 6: Розширені сценарії

#### 🎯 Завдання 6.1: Комплексний аналіз

**Мета:** Об'єднати всі навички

**Сценарій:** Ви - аналітик компанії, який повинен провести комплексний аналіз продажів.

**Кроки:**

1. Отримайте загальну картину:

   ```
   /залишки
   /ai запит:дай загальну картину продажів
   ```

2. Проаналізуйте тренди:

   ```
   /ai запит:проаналізуй тренди продажів за останній місяць
   ```

3. Знайдіть проблемні зони:

   ```
   /розумний-пошук кількість_вище:100
   /ai запит:знайди товари з низьким обігом
   ```

4. Створіть звіт:
   ```
   /ai запит:створіть детальний звіт по аналізу продажів
   ```

**✅ Критерії успіху:**

- [ ] Можете проводити комплексний аналіз
- [ ] Використовуєте всі доступні інструменти
