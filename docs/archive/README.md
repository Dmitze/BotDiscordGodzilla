# Архів документів

Ця директорія містить застарілі звіти та історичні документи (фази, міграції, тести, рефакторинг).

- Актуальна документація: див. `docs/INDEX.md`
- Архітектура: `docs/ARCHITECTURE.md`
- Безпека: `docs/security/SECURITY_GUIDE.md`
- API та команди: `docs/API_OVERVIEW.md`
- Гайд розробника: `docs/DEVELOPER_GUIDE.md`

Якщо ви потрапили сюди за старим посиланням, будь ласка перейдіть на відповідний розділ в актуальній документації.
