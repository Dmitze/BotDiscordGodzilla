# 🎯 НОВА АРХІТЕКТУРА КОМАНД ДЛЯ ЗСУ

## 📋 Огляд змін

Цей документ описує нову, гнучку архітектуру команд Discord бота, спеціально розроблену для потреб Збройних Сил України (ЗСУ). Старі команди, прив'язані до конкретних критеріїв (як `розумний-пошук` з фіксованими полями), були замінені на універсальні та адаптивні рішення.

## 🚀 Основні принципи нової архітектури

### ✅ **Гнучкість**

- Команди не прив'язані до конкретних полів або критеріїв
- Користувач може шукати будь-що за будь-якими параметрами
- Підтримка різних типів документів та даних

### ✅ **Спеціалізація для ЗСУ**

- Команди адаптовані під військові потреби
- Підтримка роботи з особовим складом, технікою, операціями
- Інтеграція з військовими документами та процедурами

### ✅ **Модульність**

- Кожна команда має чітко визначену відповідальність
- Легко додавати нові функції та команди
- Можливість розширення для різних служб

## 🔧 Нові команди

### 1. **🔍 `/пошук` - Гнучкий пошук**

```
/пошук запит:"особовий склад" тип_документа:"накази" підрозділ:"1-ша бригада"
```

**Особливості:**

- Універсальний пошук по будь-яким критеріям
- Підтримка фільтрів за типом документа, датою, підрозділом
- Налаштування кількості результатів
- Пріоритизація документів

**Параметри:**

- `запит` - що шукати (обов'язковий)
- `тип_документа` - фільтр за типом (накази, доповіді, звіти, тощо)
- `дата_від` / `дата_до` - діапазон дат
- `підрозділ` - фільтр за підрозділом
- `пріоритет` - фільтр за пріоритетом
- `ліміт` - кількість результатів (1-50)

### 2. **📄 `/документи` - Робота з військовими документами**

#### 2.1 **👥 Особовий склад**

```
/документи особовий-склад дія:"пошук" запит:"капітан"
/документи особовий-склад дія:"звіт"
```

**Дії:**

- `пошук` - пошук особового складу
- `додати` - додавання нової особи
- `оновити` - оновлення даних
- `звіт` - звіт по особовому складу
- `перевірка` - перевірка наявності

#### 2.2 **🚗 Техніка**

```
/документи техніка дія:"стан" запит:"БМП-2"
/документи техніка дія:"обслуговування"
```

**Дії:**

- `пошук` - пошук техніки
- `додати` - додавання техніки
- `стан` - перевірка стану техніки
- `звіт` - звіт по техніці
- `обслуговування` - планування ТО

#### 2.3 **📦 Матеріали (МТЗ)**

```
/документи матеріали дія:"залишки"
/документи матеріали дія:"поповнення"
```

**Дії:**

- `пошук` - пошук матеріалів
- `додати` - додавання матеріалів
- `залишки` - перевірка залишків
- `звіт` - звіт по МТЗ
- `поповнення` - заявка на поповнення

#### 2.4 **⚔️ Операції**

```
/документи операції дія:"статус"
/документи операції дія:"планування"
```

**Дії:**

- `пошук` - пошук операцій
- `додати` - додавання операції
- `статус` - статус операцій
- `звіт` - звіт по операціях
- `планування` - планування операцій

#### 2.5 **📋 Накази**

```
/документи накази дія:"пошук" запит:"безпека"
/документи накази дія:"статус"
```

**Дії:**

- `пошук` - пошук наказів
- `додати` - додавання наказу
- `статус` - статус виконання

### 3. **📊 `/аналітика` - Аналітика та звітність**

#### 3.1 **📋 Звіти**

```
/аналітика звіт тип:"щоденний" формат:"excel"
/аналітика звіт тип:"особовий склад" формат:"pdf"
```

**Типи звітів:**

- `щоденний` - щоденний звіт

- `місячний` - місячний звіт
- `особовий склад` - звіт по особовому складу
- `техніка` - звіт по техніці
- `операції` - звіт по операціях

**Формати:**

- `текстовий` - текстовий формат

#### 3.2 **📈 Статистика**


**Категорії:**

- `особовий склад` - статистика особового складу

#### 3.3 **🔮 Прогнозування**

## 🗑️ Видалені команди

### ❌ **Старі команди, які були видалені:**

1. **`розумний-пошук`** - замінено на гнучкий `/пошук`
   - **Причина:** Прив'язаний до конкретних полів (ціна, кількість)
   - **Заміна:** Універсальний пошук з фільтрами

2. **`пошук-експортовано`** - інтегровано в `/аналітика звіт`
   - **Причина:** Обмежена функціональність
   - **Заміна:** Повноцінна система звітності

3. **Старі поля пошуку** - замінено на гнучкі параметри
   - **Причина:** Фіксовані поля не підходять для військових документів
   - **Заміна:** Динамічні параметри пошуку

## 🔄 Міграція зі старих команд

### **Перехід з `розумний-пошук` на `/пошук`:**

**Старий формат:**

```
/розумний-пошук номенклатура:"зброя" ціна_вище:1000
```

**Новий формат:**

```
/пошук запит:"зброя" пріоритет:"високий"
```

### **Перехід з `пошук-експортовано` на `/аналітика`:**

**Старий формат:**

```
/пошук-експортовано поле:"назва" запит:"техніка"
```

**Новий формат:**

```
/аналітика звіт тип:"техніка" формат:"excel"
```

## 🔧 Технічна реалізація

### **Структура файлів:**

```

├── search.js          # Гнучкий пошук
├── documents.js       # Робота з документами
├── analytics.js       # Аналітика та звіти
├── operations.js      # Оперативне управління
```

### **Ключові технології:**

- **Discord.js v14** - основна бібліотека
