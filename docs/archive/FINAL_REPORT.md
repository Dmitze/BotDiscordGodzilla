## 🚀 Методи розгортання

### 💻 Локальне розгортання

```bash
# Швидкий старт
npm run setup
npm start

# Розробка
npm run setup:dev
npm run start:dev
```

### ⚡ PM2 кластеризація

```bash
# Розгортання з PM2
npm run setup:prod
npm run launch:pm2

# Управління
pm2 status
pm2 logs discord-bot
pm2 restart discord-bot
```

### 🐳 Docker контейнеризація

```bash
# Розгортання з Docker
npm run deploy:docker
npm run launch:docker

# Управління
docker-compose logs -f
docker-compose restart
docker-compose down
```

### 🔧 Системні сервіси

```bash
# Linux (systemd)
sudo systemctl enable discord-bot
sudo systemctl start discord-bot

# Windows
sc create DiscordBot binPath= "powershell.exe -File start-bot.ps1"
sc start DiscordBot
```
