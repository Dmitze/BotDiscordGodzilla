# 📊 Каталог даних (data)

Цей каталог містить усі дані, які використовує бот, включаючи метрики, тимчасові файли та інші дани

## 📂 Підкаталоги

### /metrics
- Зберігає метрики продуктивності бота
- Автоматично створюються під час роботи системи
- Використовуються для аналізу та моніторингу

### /tmp
- Тимчасова тека для тимчасових файлів
- Автоматично очищується системою
- Не призначено для зберігання важливих даних

## 🔧 Керування даними
- **Резервне копіювання**: Рекомендується налаштувати автоматичне резервне копіювання
- **Очищення**: Тимчасові файли видаляються автоматично
- **Кодування**: Всі файли зберігаються у форматі UTF-8

## ⚠️ Важливо
- Не змінюйте вручну файли в цьому каталозі під час роботи бота
- Для зміни конфігурації використовуйте відповідні команди або API
