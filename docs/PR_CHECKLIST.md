# Контрольний список для Pull Request

## 🧪 Тестування

- [ ] Усі юніт-тести успішно проходять (`npm test`)
- [ ] Інтеграційні тести пройдено
- [ ] E2E тести для основних сценаріїв виконано
- [ ] Перевірено сумісність з різними середовищами (dev/staging/prod)

## 📝 Документація

- [ ] Оновлено відповідні розділи в `docs/`
- [ ] Додано/оновлено коментарі до коду
- [ ] Оновлено `CHANGELOG.md` (якщо потрібно)
- [ ] Перевірено актуальність посилань у документації

## ⚙️ Налаштування

- [ ] Всі нові змінні середовища описані в `.env.example`
- [ ] Оновлено `docs/guides/ENV_REFERENCE.md` (якщо потрібно)
- [ ] Конфігурація для розробки та продакшну перевірена

## 🔒 Безпека

- [ ] Вразливості безпеки перевірені
- [ ] Чутливі дані не закомічені
- [ ] Дозволи та рівні доступу перевірені

## 🔧 Технічні аспекти

- [ ] Код відповідає стандартам кодування проекту
- [ ] Додано необхідні тести
- [ ] Виправлено попередження лінтера
- [ ] Перевірено продуктивність (якщо застосовно)

## 📦 Розгортання

- [ ] Оновлено версію у `package.json` (за необхідністю)
- [ ] Оновлено залежності (`npm outdated`)
- [ ] Перевірено сумісність з існуючими міграціями

## ℹ️ Додатково

- [ ] Оновлено `API_OVERVIEW.md` (якщо змінюються API/команди)
- [ ] Додано приклади використання (якщо потрібно)
- [ ] Заплановано необхідні дії для наступних ітерацій

## ✅ Перед відправкою

- [ ] Переглянуто власний код (self-review)
- [ ] Отримано необхідні апруви
- [ ] Визначено потенційні ризики та план дій у разі проблем
