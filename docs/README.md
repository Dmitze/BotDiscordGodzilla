## 🎯 Призначення

Ця документація призначена для:

- **Розробників** - технічна документація та архітектура
- **Користувачів** - гайди та інструкції
- **Адміністраторів** - звіти та аналізи
- **Новачків** - навчальні матеріали

## 📝 Як використовувати

1. **Для початку роботи** - дивіться `guides/QUICK_START.md`
2. **Для налаштування** - дивіться `guides/SETUP.md`
3. **Для розробки** - дивіться `architecture/ARCHITECTURE.md`
4. **Для API** - дивіться `api/API_DOCUMENTATION.md`
5. **Для аналізу** - дивіться `reports/`

## 🔄 Оновлення документації

Документація оновлюється автоматично при:

- Зміні архітектури
- Додаванні нових функцій
- Виправленні помилок
- Оновленні API
