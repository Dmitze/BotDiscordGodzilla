# 🧰 Утиліти (`src/utils/`)

Я створив набір утиліт для логування, безпеки, ретраїв, форматування, продуктивності, UI-хелперів, пагінації та управління чергами.

## 📦 Основні файли
- `logger.ts` — структурний логер з маскуванням секретів
- `security.ts` — безпека, валідація, політики
- `retry.ts` — безпечні ретраї з тайп-ґардами
- `performanceOptimizer.ts` — оптимізації
- `fileProcessor.ts`, `exportHelpers.ts`, `formatters.ts`
- `queueManager.ts`, `pagination.ts`, `uiHelpers.ts`
- `aiEnhanced.ts`, `formulaProcessor.ts`, `clusterManager.ts`
