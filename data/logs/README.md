# 🗂️ Логи (`data/logs/`)

Я налаштував структурне логування з ротацією та окремими файлами для кожного домену. Логи містять безпечні метадані з маскуванням секретів.

## 📦 Файли
- `bot.log` — загальні події бота
- `commands.log` — виконання команд
- `error.log`, `exceptions.log`, `rejections.log` — помилки та винятки
- `performance.log` — продуктивність і таймінги
- `security.log` — події безпеки

## 🔗 Пов'язані документи
- Логер: ../../src/utils/logger.ts
- Безпека: ../../docs/security/SECURITY_GUIDE.md
