## 🔧 **ДЕТАЛЬНИЙ ОПИС**

### **📝 Logs Directory**

#### **Структура логів**
Логи організовані за датою та типом операції:
- **Формат:** `operation_YYYYMMDD_HHMMSS.log`
- **Рівні:** ERROR, WARN, INFO, DEBUG
- **Ротація:** автоматична ротація логів
- **Зберігання:** 30 днів для INFO, 90 днів для ERROR

#### **Типи логів**
- **Системні логи** - запуск, зупинка, помилки
- **Команди логи** - виконання команд користувачів
- **API логи** - запити до зовнішніх API
- **Помилки** - детальна інформація про помилки
- **Продуктивність** - метрики продуктивності

### **📈 Metrics Directory**

#### **Prometheus метрики**
- **Counter** - кількість запитів, помилок
- **Gauge** - використання пам'яті, CPU
- **Histogram** - час відповіді команд
- **Summary** - статистика продуктивності

#### **Кастомні метрики**
- **Command Usage** - статистика використання команд
- **User Activity** - активність користувачів
- **Error Rates** - частота помилок
- **Performance** - метрики продуктивності

### **📁 Tmp Directory**

#### **Тимчасові файли**
- **Експорт даних** - результати пошуку, звіти
- **Кеш файли** - тимчасові кеш файли
- **Завантаження** - тимчасові завантажені файли
- **Обробка** - файли в процесі обробки

## 🚀 **ВИКОРИСТАННЯ**

### **📝 Робота з логами**
```typescript
import logger from '../src/utils/logger';

// Логування різних рівнів
logger.info('Інформаційне повідомлення');
logger.warn('Попередження');
logger.error('Помилка', { error: errorDetails });
logger.debug('Детальна інформація');
```

### **📈 Робота з метриками**
```typescript
import { MetricsService } from '../src/services/MetricsService';

// Збір метрик
const metrics = new MetricsService();
metrics.incrementCounter('commands_executed');
metrics.setGauge('memory_usage', process.memoryUsage().heapUsed);
```

### **📁 Робота з тимчасовими файлами**
```typescript
import { fileProcessor } from '../src/utils/fileProcessor';

// Створення тимчасового файлу
const tempFile = await fileProcessor.createTempFile('search_results.xlsx', data);

// Очищення тимчасових файлів
await fileProcessor.cleanupTempFiles();
```

### **🔍 Аналіз логів**
```bash
# Пошук помилок
grep "ERROR" logs/*.log

# Аналіз продуктивності
grep "response_time" logs/*.log | awk '{print $NF}'

# Статистика команд
grep "command_executed" logs/*.log | wc -l
```
